СТАНКЕВИЧ
Описание
СТАНКЕВИЧ — веб-система управления заявками на ремонт оборудования. Система позволяет клиентам создавать заявки с вложением фото, менеджерам — 
назначать исполнителей и контролировать ход работ, а техникам — выполнять и закрывать задачи. Предусмотрены роли, уведомления, комментарии, история изменений (аудит) и фильтрация заявок.
